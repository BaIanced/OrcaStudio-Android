# Python on demand part 2: libpython out of the APK (design 2026-11-03, Claude; UNTESTED)

Goal: drop libpython3.12.so (6.7 MB) from jniLibs; fetch it with the rest of the runtime (part 1, `Plugins.preparePythonHome`).

Facts (source-checked 2026-11-03):
- `android/core/plugins.cmake:11-15`: `orca_plugins` (static, linked into liborca_jni) links `orca_python` = imported libpython,
  `IMPORTED_NO_SONAME` -> liborca_jni has DT_NEEDED `libpython3.12.so`; it must resolve when `System.loadLibrary("orca_jni")` runs
  (`OrcaNative.kt:15`, `ObnNative.kt:9`). Bionic binds every symbol at load (no lazy binding).
- Python starts only in `Plugins.start` (after Orca Cloud sign-in; callers `AppViewModel.kt:109`, `OrcaCloudSection.kt:175`),
  python home = `<filesDir>/data/python`. `:scad` process does not load orca_jni.
- Chaquopy libpython has no DT_SONAME; for targetSdk >= 23 bionic does not fall back to the basename, so a data-dir copy cannot
  satisfy DT_NEEDED by name.

Plan (no ELF patching of the real lib needed):
1. Stub `libpython3.12.so` in jniLibs (tiny): DT_SONAME `libpython3.12.so`, every symbol libpython exports (from its dynsym,
   generated by `stage_python.py`, built with NDK clang there or as a CMake target in core) as an alias of one abort/log function
   (data symbols: zero bss objects; no copy relocs on arm64 PIC, so sizes don't matter). Plus one JNI function
   `globalLoad(path)` = `dlopen(path, RTLD_NOW | RTLD_GLOBAL)`.
2. App start (`OrcaApp.onCreate`, before anything touches OrcaNative/ObnNative): `System.loadLibrary("python3.12")` (stub); if
   `<filesDir>/data/python/lib/libpython3.12.so` exists and the `.runtime` stamp matches the asset manifest, `globalLoad` it.
   Bionic looks up symbols in the namespace's global group (RTLD_GLOBAL libs) BEFORE the local group, so liborca_jni and the
   lib-dynload modules bind to the real libpython although DT_NEEDED loaded the stub. **Verify this on the phone first**
   (tiny probe before the full change).
3. Manifest: add `file arm64-v8a.zip jniLibs/arm64-v8a/libpython3.12.so lib/libpython3.12.so`; build still links the real lib
   from `python/prefix/lib`.
4. `Plugins.start`: if the real libpython was not preloaded at process start (flag from step 2): fetch, then do NOT call
   `PluginNative.start` (stub would abort); set status "Restart OrcaStudio to finish installing the plugin runtime" + restart button.
   Guard `openPage`/`openConfig`/`pageMessage` etc. on `started`.
5. Test on the phone VD (WSA wedged): fresh data (fetch -> restart prompt -> plugins load), old part-1 data (stamp differs ->
   refetch), probe imports (ssl, sqlite3, ctypes.pythonapi) as in the part 1 test (archive 2026-11-03). Measure APK in CI, lower budgets.
Fallback if RTLD_GLOBAL precedence fails: add DT_SONAME to the fetched real lib at install time (needs a spare .dynamic slot).
